# Foliculos AI — Demo

Demo de segmentacion de foliculos en ultrasonido 2D (equipo GE Voluson) usando YOLOv8-seg.

Sube una imagen o video de ultrasonido y el modelo detecta y segmenta los foliculos, mostrando conteo, confianza y dimensiones aproximadas.
